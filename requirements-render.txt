# Render free-tier production dependencies.
#
# Why this file instead of just uncommenting requirements.txt:
#   The full BGE embedder + bge-reranker-base + PyTorch CPU runtime add up to
#   ~300 MB resident, which leaves <200 MB for Python + FastAPI + boto3 +
#   request handling on Render's 512 MB free tier. That's tight enough to OOM
#   under load. We keep the lightweight hash embedder + overlap reranker (which
#   the LLM compensates for via real Groq/Gemini reasoning) and skip the heavy
#   ML deps. Upgrade to Render Starter ($7/mo, 1 GB RAM) and set
#   USE_REAL_EMBEDDER=true, USE_REAL_RERANKER=true to switch on the full stack.
